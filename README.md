# СтройБаза

Строительный интернет-магазин на React и Vite.

## Запуск

```powershell
npm ci
npm run dev
```

Для проверки итоговой сборки выполните `npm run build`, затем `npm run preview`.
Папка `dist` содержит статическую сборку. Маршруты после `#` работают и на статическом хостинге.
https://feterm.github.io/kr1-html-css-shop/

## GitHub Pages

В настройках репозитория откройте **Settings → Pages → Build and deployment** и выберите **GitHub Actions** в поле **Source**. При пуше в `main` workflow установит зависимости, соберёт проект и опубликует папку `dist`. Результат доступен во вкладке **Actions**.


## Возможности

- Каталог с категориями, поиском, фильтрами по цене и наличию и сортировкой.
- Карточки товаров с характеристиками и отзывами, избранное, сравнение до трёх позиций и последние четыре просмотра.
- Корзина, проверка наличия, расчёт доставки, выбор даты и интервала получения, история заказов в личном кабинете.
- Общий поиск по каталогу, страницам и услугам, светлая и тёмная темы.
- Чат с автоответчиком по товарам, остаткам, самовывозу и доставке.

Магазин работает без сервера. Корзина, заказы, отзывы, избранное, история просмотров и чата хранятся в браузере. Остатки меняются после оформления заказа в этом же браузере. Чат отвечает по данным каталога, подключение к оператору не настроено. Платежи не проводятся.


Дополнительно доступны график выдачи и доставки на неделю, резерв товара, услуги с заявками и отзывами, локальная регистрация и редактирование профиля, форма сохранения адреса для спецпредложений и встроенная карта Яндекса. На главной есть десять примеров отзывов, помеченных как примеры, и отзывы, добавленные в браузере. Телефон, почта и адрес используются в качестве примера. Рассылки и серверная обработка заявок не подключены.
