# KeyForge — интернет-магазин механических клавиатур

Учебный проект по дисциплине «Фронтенд и бэкенд разработка» (ИПТИП, кафедра индустриального программирования, 3 семестр, 2026/2027 уч. год).

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина механических клавиатур **KeyForge**: главная страница, каталог с фильтрами, карточка товара, страница заявки и контакты. CSS-фреймворки не используются, JavaScript применяется минимально (модальное окно и сообщение об отправке формы).

## Описание обязательных страниц

| Страница | Содержимое |
|----------|------------|
| `index.html` | hero-блок, преимущества (`#advantages`), популярные товары (`#popular`), блок «Как сделать заказ», `aside` с помощью |
| `catalog.html` | хлебные крошки, статический блок фильтров (sticky), сетка карточек товаров |
| `product.html` | изображение, описание, цена, таблица характеристик, таблица сравнения комплектаций, FAQ, отзыв, похожие товары |
| `order.html` | форма заявки: имя, e-mail, телефон, товар, комментарий, согласие, кнопка отправки |
| `contacts.html` | карточки контактов, форма обратной связи, режим работы |

Все страницы имеют корректную структуру (`DOCTYPE`, `html`, `head`, `body`), уникальные `title` и `meta description`, единую навигацию, один тег `main`, шапку и подвал.

## Соответствие требованиям

- **Семантика:** `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- **Навигация:** единое меню на всех страницах, якорные ссылки (`index.html#advantages`, `index.html#popular`, `index.html#contacts`), хлебные крошки, `aria-current` для активной страницы.
- **Карточки:** название, описание, цена, кнопка «Подробнее», бейджи «Хит» / «Новинка» / «Скидка».
- **Таблицы:** `caption`, `thead`, `tbody`, `th`, `td` (характеристики, комплектации, часы работы).
- **Формы:** у каждого поля есть `label` (`for` = `id`), атрибуты `name`, `required`, `type="email"`, `type="tel"` с `pattern`.
- **Модальное окно:** элемент `<dialog>` с открытием через `showModal()`.
- **CSS:** внешний файл, переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`.
- **Flex/Grid:** Flexbox — шапка, навигация, группы кнопок, подвал; Grid — сетка каталога, hero, раскладка «контент + боковая колонка», каталог с фильтрами.
- **БЭМ:** `site-header__logo`, `site-nav__link--active`, `product-card__title`, `product-card--sale`, `order-form__field` и др.
- **Позиционирование:** `relative` у карточки товара, `absolute` у бейджа, `sticky` у шапки и фильтров, `fixed` у кнопки «Наверх», `z-index` заданы через переменные.

## БЭМ-блоки проекта

`site-header`, `site-nav`, `breadcrumbs`, `hero`, `advantages`, `products-grid`, `product-card`, `catalog-layout`, `catalog-filters`, `catalog-products`, `table`, `faq`, `badge`, `button`, `order-form`, `order-dialog`, `site-footer`, `to-top`.

Примеры элементов: `site-nav__link`, `product-card__title`, `order-form__field`. Примеры модификаторов: `site-nav__link--active`, `product-card--sale`, `button--secondary`, `badge--hit`.

## Самостоятельные доработки

- собственная визуальная концепция (магазин клавиатур), SVG-иллюстрации товаров в `images/`;
- расширенный каталог из шести товаров, бейджи, старая цена у товаров со скидкой, категории;
- страница товара: две таблицы (характеристики и сравнение комплектаций), блок FAQ на `<details>`, отзыв, похожие товары;
- sticky-фильтры каталога и хлебные крошки на внутренних страницах;
- доработанный сценарий заявки: кнопка «Заказать» подставляет товар в форму, `order.html?product=…` подставляет товар из ссылки, сообщение об успешной отправке;
- доступность: видимый фокус, подписи ко всем полям, `aria-describedby`, `aria-current`, `role="status"`, поддержка `prefers-reduced-motion`;
- кнопка «Наверх» (`position: fixed`), подсветка якорной цели `:target`;
- аккуратный CSS: переменные для отступов, цветов и `z-index`, последовательный БЭМ без дублирования.
